# RFxchange LinkedIn Acquisition Taxonomy

The taxonomy separates **organization type** from the **role an organization can play inside RFxchange**. An organization can hold multiple RFxchange roles.

## Organization taxonomy

| Code | Organization type | Typical RFxchange value |
|---|---|---|
| `EDO` | Economic development organization | Acquire; Resource; Amplify; Validate |
| `CHM` | Chamber / business membership organization | Acquire; Resource; Amplify |
| `GOV-BUY` | Government / public purchaser | Supply; Validate |
| `EDU-BUY` | Public-school / education purchaser | Supply; Validate |
| `SBR` | Small-business resource provider | Acquire; Resource; Amplify |
| `GOVCON` | Government-contracting resource | Acquire; Resource; Validate |
| `WFD` | Workforce organization | Acquire; Resource; Amplify |
| `ASSOC` | Industry / trade association | Acquire; Amplify; Teaming; Supply |
| `CAP` | Capital / financial resource | Resource; Capital; Acquire |
| `INNOV` | Incubator / accelerator / innovation ecosystem | Acquire; Resource; Amplify |
| `INFRA` | Port / transit / utility / public authority | Supply; Validate |
| `PRIME` | Large corporate / federal prime | Supply; Teaming; Validate |
| `INST-BUY` | University / institutional purchaser | Supply; Resource; Amplify; Validate |
| `REGIONAL` | Regional coordinating organization | Amplify; Validate; Resource; Partnership |

## RFxchange role vocabulary

- **Acquire** — can produce prospective RFxchange users.
- **Supply** — can create opportunities or purchasing demand.
- **Resource** — can provide business-development assistance or services.
- **Amplify** — has an audience/network that can extend RFxchange reach.
- **Validate** — participation increases legitimacy, trust, or verification.
- **Capital** — can provide financing or capital resources.
- **Teaming** — can create supplier/subcontractor/partner relationships.
- **Partnership** — high-value institutional or ecosystem relationship.

## Priority

- **P0** — work first; highest leverage for launch density, opportunity supply, or validation.
- **P1** — work second; strong expansion and ecosystem value.
- **P2** — work after P0/P1; edge-market, specialized, or lower immediate density value.

## Geographic rings

- **Core** — Isle of Wight and the immediate adjoining market.
- **Near** — broader Hampton Roads / Historic Triangle operating market.
- **Edge** — western Virginia and northeast North Carolina localities in the practical ~50-mile market shed.
- **Regional Overlay** — organizations whose service territory spans multiple rings.

These are operating acquisition rings, not survey-grade geospatial boundaries. A future geocoding pass can calculate precise distance from a selected Isle of Wight origin point.
